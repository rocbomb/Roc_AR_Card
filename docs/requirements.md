# AR动漫卡片召唤器 - 需求文档

## 1. 项目概述

开发一个基于 Web 的 AR 应用，用户使用手机摄像头扫描动漫卡片，即可在卡片上方看到对应的 3D 模型。

## 2. 核心功能

### 2.1 卡片识别
- 支持识别约 **10 张**特定动漫卡片
- 使用手机摄像头实时扫描
- 准确识别当前扫描的是哪张卡片

### 2.2 3D模型展示
- 识别成功后，在卡片上方叠加显示对应的 3D 模型
- 每张卡片对应一个独特的 3D 模型

### 2.3 实时跟踪
- 3D 模型跟随卡片移动
- 卡片旋转时，模型同步旋转
- 卡片远近变化时，模型大小相应调整

## 3. 技术要求

### 3.1 平台
- 纯 Web 实现（H5）
- 无需安装 App，浏览器直接访问

### 3.2 兼容性
- iOS Safari
- Android Chrome
- 需要 HTTPS 访问（摄像头权限要求）

### 3.3 技术栈
- **AR.js** - AR 识别与跟踪
- **A-Frame** - 3D 渲染
- **NFT (Natural Feature Tracking)** - 基于图像自然特征识别

## 4. 用户体验

### 4.1 使用流程
1. 用户打开网页
2. 授权摄像头权限
3. 将摄像头对准卡片
4. 识别成功，显示 3D 模型
5. 移动卡片，模型跟随

### 4.2 加载体验
- 显示加载进度/提示
- 未识别时提示"请对准卡片"

## 5. 素材清单

| 类型 | 数量 | 格式 | 说明 |
|------|------|------|------|
| 卡片图片 | ~10 张 | PNG/JPG | 用于生成识别特征 |
| 3D 模型 | ~10 个 | GLB/GLTF | 对应每张卡片 |
| NFT Marker | ~10 套 | fset/fset3/iset | 由工具生成 |

## 6. 项目结构

```
ARCard/
├── index.html          # 主页面
├── assets/
│   ├── images/         # 卡片原图（用于生成marker）
│   ├── markers/        # NFT标记文件
│   └── models/         # 3D模型文件
└── Nft-Marker-Creator-App/  # Marker生成工具
```
